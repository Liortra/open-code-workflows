# New App Idea — Recipe Box

A concept seed for a second application to run through the `build` pipeline
(see `instructions/build/`), in the same shape as `concept.md`.

---

A personal recipe box and meal-planning web app for home cooks. Use
frameworks such as Bootstrap for the frontend and FastAPI+SQLite for the
backend. Start with 20 recipes spread across a handful of categories
(Breakfast, Main, Side, Dessert), each with a title, category, ingredient
list, and step-by-step instructions. Support a Cook Mode that walks through a
recipe's steps one at a time with a checkbox per step. Include a Meal
Planner that lets the user assign recipes to days of the coming week, and a
Shopping List that aggregates the ingredients from all recipes currently
planned for the week into a single checkable list. Have an "Admin" feature
that allows the user to add new recipes.
