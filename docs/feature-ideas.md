# Feature Ideas — Hebrew Language Tutor

Brainstormed candidates for a future enhancement pass (see
`instructions/enhancements/` for the pipeline that would carry one of these
from idea to shipped feature). Not scoped or approved — just a starting list.

1. **English Text-to-Speech** — speak the English meaning aloud too, not just
   the Hebrew word, so Study mode works as a listen-and-recall drill in both
   directions.
2. **Spaced Repetition (SRS)** — track per-word recall history and surface a
   "Due for Review" queue across all lessons instead of always drilling a full
   lesson start to finish.
3. **Progress Dashboard** — a home-screen view of per-lesson mastery %,
   overall exam history, and a day-streak counter, so progress is visible at a
   glance instead of buried per-lesson.
4. **Nikud (vowel points) Toggle** — a setting to show or hide Hebrew vowel
   pointing, so learners can practice reading unvocalized text as they
   progress.
5. **Flashcard Matching Game** — a timed drag-or-click matching mode
   (Hebrew ↔ English pairs) as a lighter-weight, game-like alternative to the
   multiple-choice Quiz.
6. **Reverse Listening Quiz** — play the Hebrew word's audio and ask the
   learner to pick its meaning, without showing the written word — a pure
   listening-comprehension variant of Quiz mode.
7. **Lesson Tags/Categories** — tag lessons by topic (Food, Travel, Family,
   etc.) so learners can study across a theme instead of only in lesson order.
8. **Printable/PDF Flashcards** — export a lesson's vocabulary as a
   print-friendly flashcard sheet for offline study.
9. **Multi-User Profiles** — lightweight named profiles (no auth) so more
   than one learner on the same install can keep separate exam history.
10. **Daily Streak Reminder** — an in-app banner/badge that tracks consecutive
    days studied, to encourage a daily practice habit.
